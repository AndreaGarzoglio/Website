About me

Genoa, Italy

I have never managed to do one thing at a time. I learned to draw manga before I learned anything else, went to art school for concept art, ended up writing the lore for the creatures I was designing, and then started writing the code that makes them move. None of these replaced the one before it — they just kept stacking.

What ties them together is the same instinct: build a world first, then find out what it needs. A game needs a creature and a reason for it to exist. A web project needs an interface and a fiction to justify it. I have never been able to treat the second half as optional.
