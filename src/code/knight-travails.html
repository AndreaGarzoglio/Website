Knight Travails

Click two squares and watch the knight take the shortest route.

The path is found with a breadth-first search, and the solver ships with an annotated copy of itself you can read from the page.

Open the live version ↗ Read the code ↗

Why breadth-first

A knight's moves are all the same length, so the first time the search reaches a square it has reached it by the shortest route. No weighting, no heuristic, no second pass.

The code is part of the page

You can read the annotated solver without leaving the app, which is the point: the algorithm is the thing on display, not the chessboard.
