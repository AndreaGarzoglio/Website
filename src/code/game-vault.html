Game Vault

A tracker for the games I've played and the ones I mean to.

Rate them across several aspects, sort them into tier lists, pull titles straight from the IGDB catalogue. It runs on its own small Node server, so there is no live demo here.

No live demo: this one needs its own server.

Read the code ↗

Why there is a server

The IGDB catalogue needs an API key, and a key in front-end code is a key you have given away. A small Node server holds it and passes the results on, which is also why this one cannot live on GitHub Pages.

Rating across aspects

A single score out of ten never says what was actually good. Games are scored on several aspects and the tier list is built from those.

Built with

  • JavaScript ES6
  • Node.js
  • IGDB API
  • REST
